# V1B decision ledger

| ID | Decision | Reason |
|---|---|---|
| D01 | Preserve G1 and accepted G2.1-G2.2/T01-T03D work. | The smaller product uses the secure foundation rather than rebuilding it. |
| D02 | Native runtime data remains native-owned and read-only to Luca. | Import is a binding, not a migration. |
| D03 | Beta memory promise is native memory plus one compact Luca handoff. | Ship continuity without recreating the full Mnemos/Polyphonic system. |
| D04 | Continuity is enabled by default with disclosure and per-resident control. | Continuity is core product value while remaining reversible. |
| D05 | Only the same resident runtime/model may author its handoff. | Preserve authorship and avoid hidden personality substitution. |
| D06 | No observer handoff jobs. | A resident authors continuity only after publishing its own final. |
| D07 | Handoff work starts only after accepted/finalized publication. | Failed or ambiguous responses are not continuity authority. |
| D08 | Handoff content is private local encrypted state, never a relay event. | Minimize exposure and preserve messaging separation. |
| D09 | A user turn preempts cognition and chat always fails soft. | Background continuity cannot interfere with direct conversation. |
| D10 | Universal brain and inner-life expansion remain the long-range G2 roadmap. | Prevent scope from growing back before functional beta. |
