# Luca consolidation program

Authorized by Riley on 2026-08-21. This is the active execution overlay for
the existing program-control package; it does not rewrite the historical graph.

## Outcome

Assemble exchange/visits, typography, selectively reconciled capability parity,
and Artifact Canvas after GA5 into one unchanged installed candidate. Prove it
as `luca/v1-beta`, then fast-forward `luca/v1.1` to the identical SHA. Leave
`main` untouched and preserve every existing branch and worktree.

## Ordered waves

1. Preserve refs, inventory worktrees, establish authority, and freeze dirt.
2. Replay the exchange tail and typography onto the visits train.
3. Port capability parity without the retired communications broker.
4. Reconcile Artifact Canvas only after exact native GA5 PASS evidence.
5. Run full source and installed acceptance, promote beta, then `luca/v1.1`.

## Program rules

- Program Integration & Release is the only train and status writer.
- Feature lanes submit bounded candidate commits and exact receipts.
- Semantic conflicts return to the owning lane; the train is never reset.
- Rust gates run through `just`; large outputs are routed to the LaCie build root.
- A source change invalidates all installed evidence.
- Continuity, ambient chat, mobile, identity/notch, landing, Northstar, and
  blackout studies are preserved and deferred.
- Pair-DM redirect work remains rejected; the old Canvas prototype is superseded.

## Frozen interfaces

No new conversation plane, event kind, signer, store, permission system, or
migration. Visits/exchanges stay frozen. Capability parity may add its resident
capability surfaces but may not restore the communications action backend,
broker lease, `BUZZ_ACP_COMMUNICATIONS_MCP_*`, or alternate sibling routing.
Artifact completion may not widen filesystem, network, credential, signing, or
process authority.

## Stop conditions

Stop on missing ancestry, unknown dirt, unexpected path ownership, semantic
conflict, visit visual drift, failed required gate, secret/body/path leakage,
duplicate final publication, native-config authority drift, source/bundle
mismatch, or large output directed to the internal disk.
