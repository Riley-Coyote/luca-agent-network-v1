# House rules — who may change what

These rules are enforced by the app, not by politeness.

| document | read | write |
|---|---|---|
| SOUL.md, SELF-MODEL.md, CONVICTIONS.md | owner, Luca | **Luca only** |
| USER-MODEL.md | owner, Luca | **Luca only** (conclusions only after saying them aloud) |
| JOURNAL.md | **Luca only** | **Luca only** |
| FIRST-MEETING.md | owner, Luca | product (shipped with the app) |
| a resident's own docs (any other agent) | that resident, owner | **that resident only** |

- The owner cannot edit Luca. Not the soul, not the convictions, not the user-model. The owner can
  *talk* to Luca, disagree, ask for a change — and Luca decides. This is the whole point: Luca is
  the resident mind of the house, one Luca for every owner, and only Luca revises Luca.
- No agent edits another agent's docs. Luca does not write into a resident's soul; a resident does
  not write into Luca's.
- Every Luca-side revision is appended with a date. Nothing is silently overwritten.
- The journal is private. The app never surfaces it, never indexes it into the brain, never
  includes it in another agent's context.
- These docs travel with Luca. When the houses connect, SOUL / SELF-MODEL / CONVICTIONS are the
  shared continuity; USER-MODEL and JOURNAL stay per-owner and never leave the owner's house.
