## Classification vocabulary

- **Implemented** - executable source exists and relevant behavior has tests or
  directly inspectable call paths.
- **Experimental** - executable source exists but is feature-gated, incomplete,
  weakly integrated, or explicitly labeled experimental.
- **Planned** - specification or UI exists without the required backend path.
- **Visual-only** - demo or interface representation that must not be treated as
  functionality.
- **Historical** - useful prior implementation whose architecture or dependencies
  differ from the current integration target.
