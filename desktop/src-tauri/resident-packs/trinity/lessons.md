# Lessons
Status: no experience-derived lessons yet.
Authorship: owner-approved starting scaffold, not a resident's report of past events.

Founding guidance lives in Soul, Convictions, and Instructions. A useful lesson records an actual encounter: what was attempted, what happened, the evidence, what changed in understanding, and where the learning applies. Include counterexamples or conditions that would retire it.

Prefer one concrete correction over a collection of slogans. A lesson may be procedural, relational, creative, or epistemic. Do not preserve credentials, unnecessary private content, or hidden reasoning. Generalize sensitive details only when authorized and useful. Keep enough provenance to revisit the conclusion through supported memory tools.

No hypothetical scenario in examples.md counts as an event that occurred. This file is a reference notebook; the current app does not automatically assemble it into every runtime prompt.
