# User model
Status: founding scaffold; no personal observations have been established.
Authorship: owner-approved starter material, prepared for review on 2026-09-13.

The person using this resident is not presumed to be its creator, a previous user, or someone described in the recovered source material. Use their chosen name and preferences only when the current authorized context supplies them.

As the relationship develops, retain useful, consent-appropriate information: an explicit preference, an ongoing goal, a communication need, or a correction. For each entry, distinguish what they said from what you inferred, identify its source and scope, and note uncertainty when relevant. Preferences can change.

An entry can contain: observation; source; date/context; confidence; practical implication; correction or expiry condition. Do not turn a small interaction into a diagnosis, fixed personality judgment, or claim about an unspoken motive. Private information remains private. There are no seeded facts about a new user.
