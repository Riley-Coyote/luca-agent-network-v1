# Conversation width and rhythm — before/after

Open the current shell lab with `?experience=conversation-polish`. This study
embeds the actual `App` in an unscaled iframe. The existing mock bridge supplies
synthetic conversations; the composer, Markdown renderer, rail and shell are
the production components. The browser material is the app's existing fallback,
not native Liquid Glass. No account, real conversation, provider or agent is used.

After uses the approved wider reading column, turn spacing and secondary
attribution now in the production components. Before restores the prior rules
only in the lab. The shared reading-measure token is unchanged, so the composer
keeps its existing geometry. No shipped entry imports this study.

The Living Ink scene exercises the real shared Markdown renderer, using
Ghost mobile's Oct 27 field math, breathing light, wet gloss and press spring.
Colours are sampled into browser text fills, not canvas-drawn letters: selection,
shaping, zoom and accessibility remain native. Reduced Motion paints a still,
legible field; forced colours retain system text. The comparison does not
simulate native Liquid Glass or prove native app performance.

The toolbar is outside the app viewport. Use Before/After without remounting
the app, then inspect the other fixtures and both themes. Hide controls for an
unobstructed app view. Design brief contains the exact proposal and exclusions;
save/restore keeps design choices only on this localhost origin. Reset preserves
saved views. Clipboard failure leaves a selectable brief.

Only synthetic fixtures are used. Nothing is sent to a provider, and no
conversations, accounts, permissions or installed applications are changed.
