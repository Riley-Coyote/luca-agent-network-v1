# Current Polyphonic landing page — start here

Snapshot: September 9, 2026, after the rounded Luca logo update. This folder is the current landing page for transfer into the Polyphonic website. Older sibling landing directories are not the source of truth for this work.

## Editable source

`index.html` plus `assets/` are the complete page. The app simulation lives in `assets/demo.js` and `assets/demo.css`. It is static HTML/CSS/JS, not the desktop client and not React. Port from this code rather than regenerating from screenshots.

Run from this folder:

```sh
npm run build
npm start
```

Node 20+; these commands require no dependency install. The server serves `dist/`, so rebuild after edits. Default port is 8744; if the previous design preview is still using it, run `PORT=8745 npm start`. `npm ci` installs pinned verification tools, then `npm run verify` exercises the preview on port 8744. Do not accidentally test an older server. `dist/` and `node_modules/` are ignored.

## Latest decisions to preserve

- Keep the accepted page composition and the dot-matrix display language. Surfaces and type were retuned on 9 September 2026 (see below): warm, flat, light — Inter and JetBrains Mono, not Instrument Sans.
- Polyphonic is one home for agents with continuity, memory, history, and persistent Mnemos identity. Frame agents as collaborators, not task-named tools.
- Rounded Luca glyph is the Polyphonic mark: `assets/brand/polyphonic-solid.svg`, used in header/footer and favicon. Preserve the round stroke caps and joins.
- Existing agent glyph system stays. `assets/brand/agents.html` is an exploratory study Riley chose not to pursue; do not integrate its candidates into the product.
- The simulated rail has Projects and Agents, plus all six runtime marks. Northstar opens a second room-navigation column; selecting a room enters its conversation.
- Mira is the resident formerly called Research. Do not rename her back to a task.
- Conversation and right drawer are separate full-height cards; the conversation toolbar stays within its card. Split, popout, and rail collapse work in the demo.
- Do not reintroduce prototype character avatars or generated background artwork.
- Important illustrative interactions matter; full feature parity with the desktop app is not the goal.

**WP-06 · seven windows (10 September 2026).** Card 1's list of agents is gone. In its place the beat-1 headline and body sit left-aligned in the container (body capped at 560px), and under them a full-bleed band drifts seven Polyphonic conversation windows to the left — one agent per runtime, each showing one finished exchange, every line verbatim from `COPY.md` → *Band · seven windows*. The band is a plain block in `<main>`, not inside `.container`, so it is viewport-wide without any `100vw` arithmetic; its own `overflow` keeps the document from scrolling sideways. The track is the seven windows plus an `aria-hidden` duplicate; the keyframe runs `translateX(0 → -50%)`, linear and infinite, at 24 px/s — the 24px gap is each window's own `margin-right`, so half the track is exactly 7 × 424 px = 2968 px and the loop never jumps. It pauses on hover, on `:focus-within` (the band itself is `tabindex="0"`), and under `html[data-motion="paused"]` from the page's motion toggle. Under `prefers-reduced-motion` and below 761px there is no animation at all: the band becomes a native horizontal scroller with snap, no mask, the duplicate hidden, and a visible end. Every interior value in a window was measured off the demo's real pop-out (`.d-popout`) in the running page — surfaces, radii, paddings, header height, name and body sizes, the composer bar — and `.pw-window` joins `.app-frame, .d-popout` in the interior-token pin, so a page retune can never leak into them. Luca, Mira and Ziggy carry the sigil marks cards 2–4 use; Iris, Wren, Otto and Nia take the demo's initial-in-a-square. `assets/demo.js` and `assets/demo.css` were not touched. One assertion block was added to `scripts/verify.mjs` (commented `WP-06`).

**WP-07 · the sign (10 September 2026).** The dot-matrix band no longer scrolls. The seven-window row owns horizontal motion on this page, so the band became a sign: a fixed display that changes what it says in place, and nothing in it ever moves sideways. Its canvas is `data-scene="sign"` with `data-phrase="ONE HOME FOR"` and a `|`-separated `data-names`; the scene, its preset and its frame pump all live in `assets/dot-display.js` (the old `marquee-crisp` scene in `assets/effects.js` is left intact and unused). Two slots sit either side of a gutter the width of the marquee's old ` · ` separator — three cells — and both are placed from the WIDEST name, so the phrase never moves when the name changes. Where that pair will not fit with three cells of air at each end — measured, below 972px — the phrase is dropped and the name stands alone, centred; below 432px the sign also steps its own pitch down to 5, and below 360px to 4, so the longest name still fits, because a static `CLAUDE CODE` at cell 6 is 396px wide and a phone is not. Timings: hold 3200ms, then a 700ms change — the outgoing name dims down the ink floor into the unlit lattice (never to black), the incoming starts 200ms in with each dot up to 120ms late, rises over 380ms to a `.68` bloom and settles back to the band's `.55` in 300ms; six names, 3900ms each, 23.4s a cycle, measured. The `.55` rest is exact, not approximate: the preset carries `level .68` for the bloom's headroom and `inkLit .26 × .95 / SIGN.REST` so a resting letter renders at the WP-02b band's own `rgb(129,127,123)` and 2.502px dot — a settled hold is pixel-identical to the old glass across the whole 1440×64 canvas. The sign drives its own rAF (`signPump`) rather than the page loop, because a change already in flight must be able to finish after the toggle stops everything else; it holds still when paused, when the tab is hidden and when scrolled out of view (0 frames), it never starts under reduced motion (the settle frame is the whole of it), and it skips repainting a hold it has already drawn. The canvas is `aria-hidden`; one static `.sr-only` sentence next to it carries the full line and never changes as the sign cycles. `assets/site.css` lost the band's two 9% edge fades — they hid a marquee entering and leaving, and with nothing entering they only ate the ends of the phrase at container widths; the band's box, height and background are unchanged. One assertion block was added to `scripts/verify.mjs` (commented `WP-07`); `scripts/verify-demo.mjs` had no marquee assertions to update.


## Website integration and signup (wired 2026-09-09)

The page ships as static files at **polyphonic.chat/beta** inside the Polyphonic web app repo (`Riley-Coyote/polyphonic-v2`, `public/beta/`, deployed by Lovable). Rebuild and re-copy after any edit here:

```sh
BASE_PATH=/beta/ PUBLISH=1 \
SIGNUP_ENDPOINT=https://kknchdnrujzheulqzowv.supabase.co/functions/v1/beta-signup \
PRIVACY_URL=https://polyphonic.chat/privacy npm run build
# then copy dist/ over polyphonic-v2/public/beta/ and push main
```

`PUBLISH=1` drops the preview `noindex` tag; `BASE_PATH` rewrites asset URLs; the signup endpoint and privacy URL are written into `dist/assets/config.js` (source `assets/config.js` stays empty). A plain `npm run build` is still the local preview.

Signup backend lives in polyphonic-v2 Supabase: `beta_signups` table, public `beta-signup` edge function (validation, honeypot field `website`, per-IP rate limit, duplicate → `already_subscribed`), and service-role-only `beta-invite`, which sends the download email (`_shared/email-templates/beta-invite.tsx`) through the existing transactional email queue. Share card: `assets/share/polyphonic-beta.png` (source `scripts/share-card.html`); email images: `assets/email/` (source `scripts/email-assets.html`). Both render from the preview server with Playwright.

Copy decisions: no support matrix. The page says "Start with Claude Code or Codex for the best experience" and the marquee reads "One home for …" rather than "Works with …".
