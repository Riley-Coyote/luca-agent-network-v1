# G2 evidence

Evidence is organized as `evidence/G2/<gate>/<task>/`. Store body-free command
logs, synthetic fixtures, test summaries, review findings, hashes, screenshots,
and installed-app proof here.

Never store private continuity bodies, decrypted imports, real journals, secret
keys, credentials, provider tokens, keychain output, or raw user prompts.

Required task files when applicable:

- `commands.log`
- `results.json`
- `review.md`
- `environment.json`
- `artifact-secret-scan.json`

Native acceptance captures belong only under `evidence/G2/G2.6/` and must use
synthetic data.
