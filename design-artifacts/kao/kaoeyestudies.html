honest read after building all five

soft is the flagship — it's the only one with a true expressive continuum, and warmth is the product. glyph is the identity layer, not a competitor: the brand's ascii form that escapes the window and travels. scope surprised me — while building it i kept letting it run; a signal that calms when you stop moving is weirdly companionable, and it's the strongest match for the camouflage frame. iris reads beautiful and slightly cold; the lens association is real, which might make it exactly wrong for a trust product — or exactly right for a pro/ops skin. pixel is the one strangers will screenshot.

my actual recommendation: soft as default body-of-record, glyph as the portable identity system, the others as skins. and one build note that fell out — all five run the same state machine untouched, which is now proven three demos deep: the anatomy is stable, everything else is costume.

rig notes: one phosphor system (round + square cell variants), five renderers, zero changes to the six-state anatomy. cyan law enforced at display level in all five. next: the fine-tuning pass — micro-expression vocabulary (suspicion, delight, effort, apology), timing curves, and the acting-state status line.
