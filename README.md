# Polyphonic

Polyphonic is a macOS app where AI agents live as residents — each with their own rooms,
their own continuity, and a memory that carries between conversations. Luca meets you at
the door.

**Downloads and updates live at
[Riley-Coyote/polyphonic-app](https://github.com/Riley-Coyote/polyphonic-app).**
This repository is the source.

## Working here

- [HANDOFF.md](HANDOFF.md) — current product, architecture, branch map, completed work,
  verification state, and continuation instructions. Start here.
- [AGENTS.md](AGENTS.md) — the branch and worktree map for agents working in this tree.
- [docs/luca/](docs/luca/) — design notes, implementation specs, and run logs.

## Lineage

Polyphonic began as a fork of Buzz. The upstream Buzz readme is kept at
[docs/BUZZ_UPSTREAM_README.md](docs/BUZZ_UPSTREAM_README.md) as technical reference for
the transport and relay layers; it is not the current product specification.
